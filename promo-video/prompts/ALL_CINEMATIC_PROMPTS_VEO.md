## 6. Vertex AI API & Script Usage

### Running via Python Automation Script
The repository includes an automated script that calls Google Cloud Vertex AI Veo 3 (`veo-3.1-generate-001`) with automatic polling and fallback:

```bash
cd /Users/kat/Projects/CoExistShieldAI

# Run only Part 3-B (Wear OS & Mobile Drama):
uv run python3 promo-video/scripts/generate_veo_videos.py cut_3b_1 cut_3b_2 cut_3b_3 cut_3b_4

# Or run all cuts:
uv run python3 promo-video/scripts/generate_veo_videos.py
```

### Python SDK Direct Invocation Example
```python
from google import genai
from google.genai import types

client = genai.Client(vertexai=True, project="corald", location="us-central1")

config = types.GenerateVideosConfig(
    aspect_ratio="16:9",
    duration_seconds=8,
)

operation = client.models.generate_videos(
    model="veo-3.1-generate-001",
    prompt="Cinematic medium tracking shot at golden-hour dusk, a young Southeast Asian woman...",
    config=config,
)
```
